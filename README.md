# Sales & Lead Generation Performance, KPI Analysis Project
Business Analyst project analyzing sales and lead generation performance 
using Excel and Power BI, KPI framework design, funnel analysis, and 
stakeholder-ready recommendations.

## Overview
A comprehensive Business Analyst project analyzing lead generation performance for a sales operation, covering the full analytical lifecycle from raw data cleaning through KPI design to executive-ready reporting. Built using Microsoft Excel and Power BI.

## Tools Used
Microsoft Excel · Power BI · Power Query · DAX

## Business Context
Lead generation teams need visibility into how leads move through the pipeline from first contact to conversion and where performance gaps exist across teams, agents, sources, and campaigns. This project simulates that exact operational reporting need.

## Key Metrics Designed
- **Contact Rate** — percentage of leads actively worked, excluding untouched leads
- **Qualification Rate** — percentage of contacted leads that qualify
- **Meeting Rate** — percentage of qualified leads that convert to a booked meeting
- **Conversion Rate** — overall funnel efficiency from lead to customer
- **Revenue per Converted Lead**

## What This Project Includes
- Data cleaning of a 3,600+ record lead dataset (duplicate removal, text standardization, data integrity checks)
- 6 Pivot Tables analyzing performance by Team, Agent, City, Lead Source, Campaign, and Product
- A daily operational tracker spanning the full reporting period
- A 3-page interactive Power BI dashboard: Executive Summary, Team & Agent Performance, and Source & Campaign Analysis
- Drill-down analysis identifying specific underperforming agents and root causes
- Ad hoc analysis answering threshold-based business questions
- Documented findings and actionable recommendations for management

## Files in This Repository
